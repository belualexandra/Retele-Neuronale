Acest modul conține o interfață web demonstrativă (mock-up) pentru sistemul de predicție a timpului de livrare.

Interfața este construită folosind Flask și permite utilizatorului să introducă parametrii unei comenzi de mâncare:

Distanța
Timpul de preparare
Experiența curierului
Vremea
Nivelul traficului
Momentul zilei
Tipul vehiculului

În această etapă (Etapa 4), interfața servește ca prototip funcțional.

### Instrucțiuni de lansare a interfeței Web (UI)

Pentru a porni interfața demonstrativă realizată în Flask, urmați pașii de mai jos:

### 1️⃣ Instalați Flask (dacă nu este deja instalat)
pip install flask

### 2️⃣ Lansați aplicația Web

Rulați, din directorul principal al proiectului:

python src/app/app.py

### 3️⃣ Accesați interfața în browser

După pornirea serverului, deschideți următorul link:

http://127.0.0.1:5000


Interfața va fi afișată și poate fi utilizată pentru introducerea datelor unei comenzi (versiune demonstrativă).
